环形拼接件 DXF 生成器
====================

Windows 使用方法：

1. 从 https://www.python.org/downloads/windows/ 安装 Python 3。
2. 安装时勾选 “Add python.exe to PATH”。
3. 双击运行 `运行环形生成器.bat`。程序会打开中文桌面窗口。

本程序使用 Tkinter 桌面界面，只使用 Python 标准库，不需要安装 pip 第三方包。
关闭窗口即可退出程序，不会留下本地浏览器服务器进程。

GitHub Actions 每次仅生成 `环形拼接件生成器-windows7`：Python 3.8.10 32 位 Windows 7 兼容版本。

该版本使用塑料护盒的梯形公头/母头连接：公头下底宽度、上底宽度和伸出高度可按 0.1 mm 调整，四个梯形转角为精确 R2 mm 圆角。

如果不希望在使用电脑上安装 Python，可以在一台 Windows 构建电脑上双击
`build_windows_exe.bat`。脚本会生成：

`dist\环形拼接件生成器\环形拼接件生成器.exe`

将整个 `dist\环形拼接件生成器` 文件夹复制到目标电脑即可运行，不需要安装 Python。
构建电脑需要临时安装 Python 3 和 PyInstaller；目标电脑不需要安装它们。

默认生成的文件名格式为：

<内径>x<外径>盖<零件数量>.dxf

示例：

203x262盖4.dxf

例如内径 203 mm、外径 262 mm、零件数量 4 时，默认名为 `203x262盖4.dxf`。文件名文本框可直接修改；改变内径、外径或零件数量时会自动刷新默认名。

切割尺寸计算为：

切割内径 = 输入内径 + 板厚 × 2
切割外径 = 输入外径 - 板厚 × 2

默认激光间隙为 0.3 mm，也可以在界面中调整。

所有尺寸单位均为毫米。

塑料护盒版本固定使用梯形公头/母头连接。公头尺寸分为三项：
公头下底宽度（沿环宽/径向）、公头上底宽度（沿环宽/径向）和公头伸出高度（切向）。三项均以毫米输入，界面箭头每次调整 0.1 mm；也会拒绝不是 0.1 mm 倍数的输入。

四个梯形转角固定为 R2 mm，DXF 写入真正的圆弧，不是折线近似。公头下底宽度不能超过补偿后的切割环宽，上底宽度不能超过下底宽度。

默认输出方式是生成一个单个零件模板 DXF，零件数量只决定扇区角度，方便在钢板上复制和排版。也可以在桌面界面中选择生成完整环形布局文件。

默认会把外弧和一侧咬合边写成一条切割路径，把内弧和另一侧咬合边写成另一条切割路径，方便激光器分开走刀。界面中的“内外轮廓分成两条切割路径”可以关闭此功能。

自动尺寸是几何和加工方面的经验规则，不是经过认证的结构应力计算。
如果零件承受载荷，请根据材料、焊缝、疲劳和实际载荷进行工程验证。
