环形拼接件 DXF 生成器
====================

Windows 使用方法：

1. 从 https://www.python.org/downloads/windows/ 安装 Python 3。
2. 安装时勾选 “Add python.exe to PATH”。
3. 双击运行 `运行环形生成器.bat`。程序会自动打开浏览器界面。

本程序使用本地浏览器界面，只使用 Python 标准库，不需要安装 pip 第三方包。
启动后请保持命令提示符窗口运行，关闭该窗口会停止本地界面。

如果不希望在使用电脑上安装 Python，可以在一台 Windows 构建电脑上双击
`build_windows_exe.bat`。脚本会生成：

`dist\环形拼接件生成器\环形拼接件生成器.exe`

将整个 `dist\环形拼接件生成器` 文件夹复制到目标电脑即可运行，不需要安装 Python。
构建电脑需要临时安装 Python 3 和 PyInstaller；目标电脑不需要安装它们。

生成的文件名格式为：

<内径>x<外径>+<两侧总补偿>补.dxf

示例：

203x262+6补.dxf

例如界面输入板厚 3 mm，文件名中的 `+6补` 记录内外两侧合计补偿 6 mm。

切割尺寸计算为：

切割内径 = 输入内径 + 板厚 × 2
切割外径 = 输入外径 - 板厚 × 2

默认激光间隙为 0.3 mm，也可以在界面中调整。

所有尺寸单位均为毫米。

默认启用“根据环宽自动设计缺口”。缺口尺寸根据径向环宽
（外径 - 内径）/ 2 自动计算，同时在拼接区域保留连续连接宽度。
自动缺口比例默认为径向环宽的 25%。
取消勾选后可以手动输入缺口尺寸。

缺口形状可以选择“梯形”（与原始 DXF 相同）或“矩形”（方形台阶）。

默认输出方式是生成一个单个零件模板 DXF，零件数量只决定扇区角度，方便在钢板上复制和排版。也可以在浏览器界面中选择生成完整环形布局文件。

自动尺寸是几何和加工方面的经验规则，不是经过认证的结构应力计算。
如果零件承受载荷，请根据材料、焊缝、疲劳和实际载荷进行工程验证。
